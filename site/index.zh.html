Surf 仍在早期开发阶段。它跟随 DeepSeek Harness（dsh）0.1.1-rc.2，暂时不会自我更新。

DeepSeek Harness 的原生 Mac App。

Surf 给 dsh 一扇真正的 Mac 窗口：原生的会话列表、系统通知、独立的设置窗口和完整的快捷键。对话四周的这层框架由 Swift 写成，可以在 App 运行时重建。

原生代码，在你眼前换上去。

插件的 Swift 目录会编译成一个以内容哈希命名的模块，然后原地替换上一代。

SessionsPlugin.swift
// 一个 C 入口点。整个 ABI 就这么多。
@_cdecl("surf_plugin_entry")
public func surf_plugin_entry() -> UnsafeMutableRawPointer {
    Unmanaged.passRetained(SessionsPlugin()).toOpaque()
}

final class SessionsPlugin: SurfPlugin {
    func activate(host: SurfHost) -> AnyObject? {
        let handle = SurfPluginHandle()
        host.register(slot: "sidebar") { AnyView(SessionListView()) }.kept(by: handle)
        return handle  // host 松手 = 这一代退役
    }
}

什么会留到下一个会话。

一个装着 markdown 文件的文件夹：索引每一步都进上下文，置顶的整篇进，正文只在需要时才读。

置顶 copy-style 短、事实性、不写安抚话。
native-abi-notes 旧镜像永远不卸载。
toolbar-contracts 元数据重建；流量原地更新。
release-checklist 公证两次，各自装订，按这个顺序。

智能体用它本来就有的读、写、grep 来编辑这些文件。这是这里唯一不含 macOS 代码的插件，所以 dsh 跑到哪它就跑到哪。

一个注意点：触及写入路径的提示注入会跨会话留存。

需要 macOS 27

装好 dsh，把 Surf 拖进「应用程序」文件夹，打开它。Surf 会在启动时拉起后端、退出时停掉。不需要 Xcode，也没有要配置的东西。
