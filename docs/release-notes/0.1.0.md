# Surf 0.1.0

首个公开版本。Surf 把 [dsh](https://github.com/deepseek-ai/deepseek-harness)（DeepSeek Harness）的界面装进一个 macOS 应用。

## 要求

- macOS 27 或更高版本。
- dsh，版本钉在 `0.1.1-rc.2`：

  ```sh
  npm i -g @deepseek-ai/dsh@0.1.1-rc.2
  ```

不需要 Xcode，不需要其它构建工具。

## 安装

1. 装 dsh（上面那条命令）。
2. 下载 `Surf-0.1.0.dmg`，把里面的 Surf 拖进「应用程序」。
3. 双击 Surf。首次打开时 macOS 问一次是否确定打开从互联网下载的应用程序，点「打开」。

应用经 Developer ID 签名、Apple 公证。默认由应用自己启动一个 dsh，⌘Q 退出时一并停止。详见[安装与使用](https://github.com/wbopan/surf/blob/v0.1.0/docs/use/install.md)。

## 有什么

- 原生会话边栏：新建、搜索、按工作区 / 按时间 / 按状态分组，行首显示会话状态。
- 原生设置窗口（⌘,）：通用、模型、插件、智能体预设，以及这个应用连接哪个后端。
- 桌面通知：需要批准、agent 提问、回合结束、出错时通知，可直接在通知上批准或拒绝。
- 跨会话记忆：一个 markdown 目录，索引每步注入、正文按需读。
- 网页界面贴近系统外观：工具栏、材质、字体、滚动跟随 macOS。
- 界面本身是 Swift 插件，源码存盘一两秒后在运行中的窗口里替换，不重启任何进程。

## 已知边界

- 没有自动更新。换版本重新下载 dmg 替换即可，应用会在下次打开时更新自己的文件。
- dsh 版本钉住。换成别的版本后界面可能错位或缺块。
- dsh 必须在登录 shell 的 PATH 上（读 `.zprofile`，不读 `.zshrc`）。连接页面会写明找不到 dsh。
- 部署目标 macOS 27.0。
